## Failures / Warnings

- SSH entrypoint intermittently timed out during monitoring, but the tmux job completed successfully.

- Directly training on all 9,429 accepted rows would overweight copied trajectories and may reduce diversity.

## Analysis

This RFT round is a good verifier and self-sampling experiment, but not a clean self-improvement signal by itself. A0 is already highly deterministic on these prompts. Even at `temperature=1.0`, most accepted generations reproduce the original gold trajectory exactly.

The best next training dataset is not the raw 9,429 accepted rows. The cleaner choice is:

```text
original 2.4k SFT + 1,095 changed accepted RFT trajectories
```

This keeps the proven baseline data while adding only the sampled trajectories that actually differ from the original answer trace and still pass the verifier.

For the resume project, the result is still useful: it shows the project measures verifier pass rate and diversity, and rejects the naive "more accepted samples is automatically better" story.
