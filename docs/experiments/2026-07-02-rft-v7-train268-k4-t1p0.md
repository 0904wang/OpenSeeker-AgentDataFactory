## Failures / Warnings

- `45/268` prompts had no accepted candidate under K=4. The failed IDs concentrate in the harder relation-diverse profiles, especially award and some education/employer rows.
- `birthplace_country` is still saturated: most accepted candidates copy the original gold trace, so it should be downweighted in the next RFT SFT mixture.
- The sampler used `--batch-size 1`, which is reliable but slow. Future larger RFT rounds should add resume support or use sharded/batched sampling.

## Analysis

This RFT pass is a stronger self-improvement signal than the earlier v6 round. The pass rate dropped from the old saturated setting to `0.7612`, and the accepted changed pool is large enough to train on (`489` changed trajectories from 268 prompts). The changed accepted examples are exactly where v7 heldout failed: education, employer, and award relation-path selection.

The best next continued-SFT mixture should avoid naively training on all 816 accepted rows. A cleaner mixture is:

```text
current 3.5k mixed SFT baseline
+ 268 v7 gold rows
+ 489 v7 changed accepted RFT rows
```

This keeps the existing v3-v6 competence, teaches the new relation-diverse gold paths, and adds verifier-approved sampled variants without overweighting copied birthplace traces.

For the resume project, this is a useful RFT result: the project can report verifier pass rate, rejection reasons, trajectory diversity, and changed accepted trajectory count rather than only saying that more synthetic data was generated.
